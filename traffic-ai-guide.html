用 OpenCode 做出紅綠燈辨識網頁

這個課堂示範的網頁是我用 OpenCode 生成的。依照下面的步驟，在 Windows 裝好 OpenCode、貼上提示詞，就可以請它在你的專案資料夾建立自己的版本。

  1. 安裝 OpenCode
  2. 開啟專案
  3. 貼上提示詞
  4. 用瀏覽器驗收
手冊目錄 安裝 OpenCode 開啟專案 生成網頁的提示詞 測試網頁 發布網頁

1. 安裝 OpenCode

  1. 在 Windows 安裝 Node.js 的 LTS 版，完成後重新開啟「命令提示字元」或 CMD。Node.js 下載頁
  2. 在 CMD 逐行執行以下指令。看到 OpenCode 版本號就可以繼續。這份手冊以 OpenCode v1 的終端介面為例。
node --version
npm --version
npm install -g opencode-ai
opencode --version

如果 CMD 顯示找不到 node、npm 或 opencode，先關掉整個終端視窗再開一次，並查看上一條安裝指令是否成功。OpenCode v1 安裝文件

2. 在專案資料夾啟動

  1. 在 Windows 檔案總管建立一個空資料夾，例如 traffic-ai-web，並打開它。在上方的地址列輸入 cmd，按 Enter。
  2. 在 CMD 輸入 opencode。開啟後，在 OpenCode 的輸入框輸入 /connect，依畫面連接課堂指定的模型服務商。若需要 API 金鑰，貼在連線設定的欄位。
  3. 輸入 /models 選擇可用模型，按 Tab 切到 Build 模式。看到輸入框旁顯示 Build，就可以貼下一節的提示詞。

模型服務商設定 · OpenCode 代理模式

3. 請 OpenCode 生成網頁

把下方整段貼進 OpenCode 的輸入框，按 Enter 送出。它會依提示在目前的資料夾建立檔案。遇到終端權限提示，先看要執行的指令是否與這個專案有關。

請在目前的專案資料夾直接建立一個繁體中文的「路口紅綠燈辨識」網頁。請實際建立檔案並執行測試。

1. 使用 HTML、CSS、JavaScript，以 index.html 為入口。畫面提供「選擇照片」「開始辨識」和結果預覽。保留原圖比例，並讓手機和電腦都能使用。
2. 請自行處理辨識所需的模型與執行環境，不需我提供照片、資料集或模型。可使用能在瀏覽器執行、具備紅綠燈類別且允許公開部署的現成模型。辨識後在原照片上框出紅綠燈位置，標示信心分數。請實際跑模型，不使用預先畫好的框或模擬結果。
3. 顯示「模型載入中」「辨識完成」「未偵測到紅綠燈」與清楚的錯誤訊息。所有網頁資源使用相對路徑，讓成品可以部署到 GitHub Pages 的專案子路徑。API 金鑰只留在本機的服務設定。
4. 自己找可用於測試的照片，至少測一張有紅綠燈和一張沒有紅綠燈的照片。用本機 HTTP 服務開啟網頁，檢查模型能否載入、按鈕能否執行、框是否落在燈的位置。
5. 完成後告訴我入口檔案、可直接開啟的本機測試網址，以及你實際驗證過哪些功能。如果卡住，請指出是模型載入、網頁執行，還是辨識結果出了問題。

4. 在瀏覽器驗收

  1. 開啟 OpenCode 回傳的本機網址。選一張看得到號誌的路口照片，按「開始辨識」，等網頁顯示結果。
  2. 看辨識框是否落在燈頭上。換一張沒有紅綠燈的照片，檢查網頁能否完成辨識並顯示零個結果。
  3. 若網頁報錯，把畫面上的完整錯誤訊息貼回同一個 OpenCode 對話。修好後再用同一張照片驗證。
剛才測試出現以下錯誤。請在目前專案找出原因、修改程式，並用同一張照片重跑。請回報實際看到的結果與測試網址。

5. 讓同學用網址打開

本機驗收後，再將成品放上 GitHub Pages。這一步需要 GitHub 帳號，以及對指定倉庫的發布權限。GitHub Pages 設定文件

請把已通過本機測試的網頁發布到我指定的 GitHub Pages 倉庫：（貼上倉庫網址）。

先確認 index.html 和必要的網頁資源位於實際發布目錄。若需要我登入或啟用 Pages，請告訴我在 GitHub 哪裡操作。發布後請用公開 HTTPS 網址確認網頁可以開啟，再跑一次照片辨識。最後把可以分享給同學的網址給我。

拿到公開網址後，用無痕視窗開啟並選圖測一次。能看到網頁並完成辨識，就可以分享給同學。
